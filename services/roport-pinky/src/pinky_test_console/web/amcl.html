파란 화살표 = AMCL 위치, 원 = 위치 표준편차(1σ). 주황 점 = 배치 yaml 노드(N12 = Nav2 전환). 위 = 창가, 아래 = 통로.
시험 순서 (03 공용 내부공간 + N12)
  1. 준비: 터미널 1에서 bringup(라이다·바퀴), 터미널 2에서 mode:=amcl 콘솔. 이 모드는 Nav2 주행을 띄우지 않아 로봇이 스스로 움직이지 않습니다.
  2. N12: 로봇을 간선 끝 N12 가로선 위에 +x 방향(입구 쪽)으로 놓고 「N12」 초기 위치 → 「제자리 갱신」을 3~5번 누릅니다.
  3. 점수: 「10 cm 안」이 80% 이상이고 빨간 점이 벽 한 곳에 몰려 있지 않은지 봅니다. 실제 위치(N12 좌표)를 넣고 「기록」.
  4. 03 안: 로봇을 손으로(또는 콘솔 조종 0.10 m/s로) 4~5곳에 옮깁니다. 줄자로 잰 실제 위치(cm)를 넣고 「제자리 갱신」 몇 번 → 「기록」. 예: G1·G2·G3 앞(x 170), 상자 옆, 입구.
  5. 결과: CSV를 Jira FFT1-123 댓글에 첨부합니다. 위치 오차·점수가 나쁜 곳은 지도(배치 yaml) 또는 실측을 다시 확인합니다.
좌표는 실측 도면 v13 기준(cm, 원점 = 콘센트 벽·통로 모서리, x = 길이, y = 창가, 방향 0° = +x). 합격 기준 80%는 제안값입니다.
