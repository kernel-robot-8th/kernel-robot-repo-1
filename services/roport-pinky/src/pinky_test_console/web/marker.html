확인 순서
  1. ID 확인: 인쇄한 마커를 한 장씩 카메라 앞에 대고, 화면의 ID·이름이 종이에 적힌 라벨과 같은지 봅니다. 오른쪽 목록에 ✓가 생깁니다.
  2. 방향: 보라 점이 종이의 왼쪽 위 모서리에 찍히면 위아래가 맞게 붙인 것입니다.
  3. 거리: 시험 시트(ID 0)를 줄자로 거리를 바꿔 가며 대고, 「인식률」이 떨어지는 거리를 기록합니다(정면·45°).
  4. 부착 후: 로봇을 실제 정차 자리에 두고 벽 마커(P·Gate)가 보이는지 확인합니다.
이 화면은 인식만 확인합니다. 모터는 움직이지 않습니다. 결과는 Jira FFT1-74 또는 Confluence 「ArUco 마커 ID 표」의 시험 기록표에 적습니다.
