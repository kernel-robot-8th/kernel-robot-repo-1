# ArUco 마커 (v1.5)

Jira: [FFT1-74](https://fp-team1.atlassian.net/browse/FFT1-74). 시연 공간의 위치·게이트·선반·포장물품·트레이에 붙이는 ArUco 마커 ID 표와 인쇄 파일입니다.
v1은 실측 전에 배정했습니다. 부착 위치·높이를 실측한 뒤 갱신합니다.

- v1.1(2026-10-29): 인쇄해 보니 150 mm가 커서 P·Gate를 100 mm로, 포장물품을 60 → 50 mm로 줄였습니다. ID는 그대로입니다.
- v1.2(2026-10-31): P7을 물류 Pinky·스마트카트 공용으로 정하고, 예비였던 ID 27을 입국장(ARR)에 배정했습니다.
- v1.3(2026-10-31): P4·P7을 **20 mm 바닥 부착**으로 바꿨습니다. 선반·OMX 자리 때문에 벽에 붙일 수 없고 진입로가 짧아, 큰 마커를 바닥에 두면 카메라에 다 들어오지 않습니다. 벽 마커는 인식되는 범위에서 바닥에 최대한 가깝게 붙입니다. 선반·포장물품 마커는 OMX용이라 OMX 담당이 크기·부착을 확인합니다.
- v1.4(2026-11-06): OMX 인도장 선반을 **2×3(6칸)**으로 다시 만들어(OMX 선반 도면 Rev A, 2026-11-05) 선반 ID를 **11~14 → 28~33**으로 옮겼습니다. 크기는 **20 mm**이고, 혹시 몰라 **30 mm**도 같이 인쇄합니다. 11~14는 예비로 돌립니다(v1.3 선반 인쇄물은 버림).
- v1.5(2026-11-09): Pinky 트레이 모서리(23~26)를 쓰지 않기로 해서 **25·26을 물류 Pinky 정밀 도킹 마커**로 바꿨습니다. 상차 노드 가로선에서 멈춘 Pinky 카메라가 정면으로 보는 OMX 받침 앞면, 세로선 연장선 위에 **세로로** 붙입니다(20 mm, 렌즈 높이 6.3 cm 근처). 25 = N01(P4, OMX3), 26 = N11(P7, OMX1·2). 23·24는 예비(N21·N22 도킹 후보). P4·P7 바닥 마커(4·7)는 그대로입니다.
- v1.5 추가(2026-11-10): Gate 1·2·3(8~10)·입국장(ARR 27)을 **100 → 60 mm**로 줄였습니다(벽에 붙였을 때 너무 큼). Pinky 카메라(초점 약 540 px)로 60 mm는 1 m에서 약 32 px, 2 m에서 약 16 px라 먼 거리 인식은 시험이 필요합니다. 다른 벽 마커(P1~P3·P5·P6)는 100 mm 그대로입니다.

- 사전: `DICT_4X4_50`. ID를 늘려야 하면 `DICT_4X4_100`으로 바꿔도 ID 0~49의 무늬는 같습니다(OpenCV 4.6에서 확인).
- 크기는 **검은 사각형 한 변**입니다. 흰 여백은 크기에 포함하지 않습니다.
- 원본은 [markers.yaml](markers.yaml)입니다. 코드에서 ID를 쓸 때도 이 파일을 기준으로 합니다.

1. 인쇄 설정에서 **실제 크기(100%)**를 고릅니다. "페이지에 맞춤"을 켜면 크기가 바뀝니다.
2. 인쇄 후 페이지 위의 100 mm 자와 검은 사각형 한 변을 자로 재서 확인합니다. 1 mm 이상 다르면 다시 인쇄합니다.
3. 회색 모서리 표시를 따라 자릅니다. 흰 여백을 남겨야 인식됩니다. 반사가 적은 무광 종이를 권장합니다.
4. 붙일 때 구김·말림이 없게 평평하게 붙입니다.

## 다시 만들기

```bash
python3 docs/aruco/generate_markers.py --check
```

- OpenCV(`cv2.aruco`)와 PyYAML이 필요합니다. PDF는 외부 라이브러리 없이 만듭니다.
- `--check`는 만든 PNG를 다시 인식해 ID가 맞는지 확인합니다.
- 같은 입력이면 같은 파일이 나옵니다. `markers.yaml`을 고친 뒤 생성 결과도 함께 커밋합니다.
